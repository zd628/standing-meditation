# 🌳 Standing Meditation (Zhan Zhuang)

A personal study and practice website for Zhan Zhuang (站桩) — Chinese standing meditation, based on the system of Master Lam Kam-Chuen.

## Overview

This site integrates Master Lam's book *The Way of Energy* (1991) with the Channel 4 documentary series *Stand Still Be Fit* (1995), providing a systematic learning path through 5 core standing postures, from beginner to advanced.

## Features

- **5 Posture Pages** — Step-by-step practice guides with YouTube video embeds, mental imagery, correction tables, and quick reference cards
- **Progressive Course Structure** — Beginner → Intermediate → Advanced, following Master Lam's curriculum
- **Warm-up & Cool-down Library** — All exercises from the 10-episode series
- **Mind Maps** — Visual diagrams of posture relationships, energy flow, mental imagery system, and Daoist philosophy
- **Cheatsheets** — One-page quick reference cards for each posture
- **FAQ & Glossary** — Common questions, body reactions, and Chinese-English terminology
- **Daily Life Applications** — How to apply Zhan Zhuang principles in everyday activities
- **Further Learning** — Public resources and links for continued study
- **Dark Mode** — For low-light practice environments

## Tech Stack

- [Astro](https://astro.build) — Static site generator
- No external CSS frameworks — custom design system
- [Mermaid.js](https://mermaid.js.org) — Mind maps and flow diagrams (loaded via CDN)
- YouTube iframe API for video embeds

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
